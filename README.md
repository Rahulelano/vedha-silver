# Vedhav Silvers Showcase

Create a premium modern luxury e-commerce website for Vedhav Silvers, a Chennai silver jewellery brand for women and kids. Implement a polished, mobile-first storefront inspired by the supplied brief: metallic silver/platinum/charcoal palette, Playfair Display headings, Inter body, Poppins product prices; premium hero, collection and product carousels, best sellers, categories, new arrivals, benefits, testimonials, Instagram gallery, newsletter, and full detailed footer using the supplied brand address/phone/social links. Create strong interactive client-side shopping UI: shop/category/product detail views, quick view, wishlist, cart, product variants, quantity controls, cart summary, mock checkout flow and account/wishlist pages or accessible navigation for them. Use refined animations and glassmorphism sparingly for an elegant premium feel. Use high-quality representative jewellery imagery from permitted image sources/placeholders. Focus on a functioning beautiful frontend prototype; do not set up external payment, auth, or backend services unless necessary. Ensure responsive design and build passes.
